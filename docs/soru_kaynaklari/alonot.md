# alonot.com İndirme Listesi (2026-11-20)

> **Köken teyidi:** GK klasöründeki dosyaların ~40'ı Windows indirme kaydına (Zone.Identifier) göre `alonot.com/download.php`'den inmiş. Kullanıcı da doğruladı. Diğer kaynaklar: kpss.digital (2 dosya), guncelkpssbilgi.com (Osmanlı 1000 soru), editoryayinevi.net (Vatandaşlık çalışma yaprakları, yayınevinin ücretsiz öğrenci içeriği), Google Docs (2 Güncel Bilgiler dosyası).
> **İndirme:** İndirmek için siteye üye olmak gerekiyor ve kullanıcı içerikleri telif açısından doğrulanmamış. Bu yüzden indirmeyi **kullanıcı kendi tarayıcısından** yapar. Claude dosya açmadı.
> **Site beyanı** ([Kullanım Şartları](https://alonot.com/kullanim-sartlari/)): "Yüklenen içeriklerin sorumluluğu ilgili kullanıcıya aittir." Lisans belirtilmemiş, footer "Tüm hakları saklıdır" diyor. → Tüm dosyalar **🟡/🔴 telifli kabul edilir**. `notlar/` = olgu kaynağı, `sorular/` = yalnızca tarz ve dağılım referansı.
> İndirdikten sonra `scan_pdf` taramasıyla (bkz. README köken tablosu) asıl üretici izleri kontrol edilir. Yayınevi izi çıkan dosya `sorular/`'a taşınır.
